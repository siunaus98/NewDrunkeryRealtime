# 教学模式与营业前说明

## 入口与引导

标题的“教学模式”进入十二张卡片组成的选关页，全部小关立即开放。鼠标点击或方向键/WASD选择、Enter/Space确认；Esc/K返回标题。退出小关回到选关页，可以重新选择任意课程。

每关仅实例化当前所需设施、碰撞与练习对象。地图上的小沙已移除；底部指引左侧保留只有头与圆球小手的头像，短句继续以小沙风趣的口吻引导当前操作，无需主动对话。操作目标使用金色高亮和箭头；采集选项出现后隐藏额外箭头，避免遮住卡片。右上角独立保留重置/补给、直接下一关与退出。F5重置，任务完成后Enter继续；说明页可点击“听下一句”或Enter。

教学不启动随机客流、怪物刷新、特殊机制和营业倒计时；客人耐心暂停自然消耗。食材自动补给，采集选择放宽到5秒，练习敌人降低生命、速度和伤害。切、磨、烤完成后均留台，由玩家主动J取走，沿用正式规则。

重置恢复该关开始时的菜单、祝福等快照，清理手持物、掉落、交互和访客。教学资源和状态不写入正式局。直接选关也会独立准备本关所需物品与设施。正式客人与BOSS的道数显示、采集卡片布局及祝福刷新说明同步使用更新后的界面。

## 每日机制卡

确认营业难度后、进入备菜前，逐张显示当天生效机制与BOSS说明卡，无机制日不弹卡。包含圣甲虫、风沙跳板、流沙、三种小BOSS、最终巨蜥和特殊客人收尾说明。

每张至少显示3秒，暂停游戏与营业计时；之后新按任意键或鼠标左右键继续。长按重复、抬键、双击不能跳过下一张锁定期；确认键不会泄漏成冲刺或攻击。最后一张结束后进入备菜。

## 验证

`tools/validate_tutorial.gd` 从标题进入十二卡选关页，经过真实加工、装盘、接单、甜品、精英逐道耐心恢复、商店、采集、战斗触碰入库、技能前后切配对比、祝福刷新与访客完成课程。检查十二关地图、设施隔离、地图无向导实体、头像与文字无重叠、提示长度、面板边界、订单避让、退出重选和正式局资源隔离；`--capture`生成选关页与各关实际渲染截图。

相关回归包括采集UI、加工熟成度、普通及精英订单/甜品、采集中断和每日状态、技能能量、机制卡3秒锁定、菜单输入与结算布局。部分既有测试场景退出时仍报告ObjectDB/资源清理诊断，需与运行中的脚本错误区分。
