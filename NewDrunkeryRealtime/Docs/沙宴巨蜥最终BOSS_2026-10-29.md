# 沙宴巨蜥：最终BOSS原型

本文件以2026-11-07的“投喂、背后弱点、修理”修订为准，覆盖旧版锁定台面食物、重击解救设施和失控后自动恢复规则。

## 进入与通关

正式流程在第七天选择关卡后生成巨蜥，仍在备菜时间过半出现。三种地图机制遵循当天解锁状态，巨蜥不额外强化它们。

独立试玩入口为项目根目录 `试玩沙宴巨蜥.cmd`，参数 `--test-monitor`。备菜8秒，第4秒生成36000生命的巨蜥；营业20秒后特殊客人到场，关闭其他地图机制方便观察。当前编辑器运行参数保留 `-- --test-monitor`，F5/F6同样启用专项测试。结束测试时清空 `editor/run/main_run_args` 即可恢复正常流程。

击杀掉落3份巨蜥珍脊，必须手动搬回。沙宴珍脊盛筵需要巨蜥珍脊（指定火候）、全熟红鬃羊肉、全熟沙薯、切旱霜白菜、细磨莳萝、绿洲葡酒，共6份，其中仅1份BOSS食材。

特殊客人“沙海宴会评审”要求盛筵、王庭烤拼和绿洲葡酒，独立600秒耐心、60秒接单，沿用半耐心压力、逾期扣声望、新到客人无收益、剩余耐心收益和连续补客规则。完成后整局通关，不进入第八天。特殊食材和对应料理不作为投喂、偷取或暴怒清箱目标。

## 偷食头：准备 → 偷取 → 进食

- 准备30秒：料理区出现可到达的空地标记。优先选取料理区玩家所在的连通空地；无人时选择最大连通空地区域，排除设施包围的小口袋。半血前1处、低于半血2处，标记之间至少间隔2.5格。标记不产生实体碰撞，但暂时保留该格，不能放置设施覆盖。
- 玩家对标记按J放入或取回食材、半成品、失败品或非酒水菜品，准备期间可更换。直接放在标记范围内的地面食物同样有效。每处只取一份；小料仅扣一份，盘子内容仅取一份，盘子不被吞掉。沿用特殊食材/料理保护。
- 准备期间巨蜥正常行动、攻击并转向战斗区玩家，保护背后弱点。
- 到期统一抓取投喂物，固定本轮结果，不能再取回骗出免费破绽。伸舌1.8秒、收舌1.5秒期间继续正常移动、转向和战斗，不因运送食物提前进入虚弱，也不取消正在进行的战斗技能；舌头不能通过攻击打断。食物在收舌结束、抵达嘴里时才结算菜品伤害并触发进食晕眩；若途中击杀巨蜥，尚未吞下的食物在投喂位置返还。
- 任一标记空缺则暴怒，每轮最多随机清空一个有库存的普通食材箱（包括其常温与冷冻库存），双空缺也不翻倍。箱子有红色叉号反馈，玩家同时收到提示。没有合法有库存箱子时不清空其他对象。
- 投喂结束后清理临时标记；未消耗的盘子、小料或其他存物留在原位置，不随标记删除。

进食测试数值：

| 投喂物 | 晕眩 | 对BOSS直接伤害 |
| --- | --- | --- |
| 失败品 | 1秒 | 无 |
| 生食材 | 1.5秒，第二/第三获取层级额外0.5/1秒 | 无 |
| 半成品/一份小料 | 3.5秒，第二/第三获取层级额外0.5/1秒 | 无 |
| 初级/中级/高级菜品 | 5/7/9秒 | 最大生命值2%/4%/6% |

双份晕眩累加，上限10秒；菜品伤害分别计算。菜品直接伤害不叠加背后倍率。进食期间不造成碰撞伤害。

## 战斗、弱点与女神像传送

背后金色圆形标记与实际受击中心跟随巨蜥完整身体姿态，包括跳跃平移、旋转和缩放；背后伤害相对可见身体判断。实际近战命中背后造成2倍伤害，正面不获得旧版“吃料理后全身增伤”。巨蜥仅在普通行动时以每秒90度转向，转身180度需要2秒。远处追近最近的战斗区玩家，近处绕玩家换位，移速80；普通移动朝向换位目标，技能即将就绪（剩余0.3秒内）改为对准玩家，近身时短暂停步对准，避免穿过目标后反复追转而无法施法。发现诱饵时优先转向诱饵。普通追逐沿头部朝向前进，目标在身后时先转头；跳跃和猛冲也始终沿头部朝向，地图边界只缩短前进距离，不将位移折向侧方。自动释放技能前等待目标进入正前方30度范围，随后前摇、位移和后摇均锁定朝向，玩家可在技能期间绕背；吐口水准备/飞行/后摇以及进食晕眩期间同样停止转向；偷食头伸舌/收舌本身不再锁定朝向或停步。

主动技能仍为扑咬、横扫甩尾、吞食猛冲，保留预警、碰撞移动与战斗区边界检查。战斗区地面食物仍可吸引巨蜥靠近进食，但已经开始的料理区投喂优先，不会被新诱饵取消。

战斗压力补充：扑咬落地半径由180扩大到240像素，与蝎子跳砸、秃鹫俯冲一致，预警圈和伤害共用该半径。吞食猛冲前摇由1.5秒缩短为0.65秒，沙虫横冲也统一为0.65秒，保留提前锁定的路线提示。

新增独立近身技能“双颚连咬”：玩家进入前方300像素内，冷却就绪并对准后优先发动。第一口预警0.55秒，第二口间隔0.35秒，每口20点基础伤害，扇形总角度约86度；两口共用锁定方向与攻击原点，不追踪绕背玩家。连续咬击结束后后摇1秒、冷却4秒，冷却可在其他技能期间恢复，但不会打断正在进行的攻击、吐口水或进食晕眩；投喂运输本身不阻止近身技能。首轮冷却1.5秒。连咬保留原有主技能剩余冷却，不重置主循环；扇形地面预警、咬合线与身体前探提供反馈。离开战斗区不发动。

绕背窗口调整：扑咬、横扫甩尾、吞食猛冲后摇由1.5秒延长到2秒，双颚连咬由0.5秒延长到1秒；期间停步、锁定朝向，不接新攻击，便于移速较高的玩家绕背输出。厨房双头运输时长和进食晕眩不变。

扑咬最少前进256像素（2格），猛冲最少384像素（3格），近身目标也不会缩短到原地。两者仍沿头部朝向，前方合法空间不足最小距离时，在预警前改用横扫，不能侧跳、倒冲或越过边界强凑距离；冲刺途中遇到实体障碍仍会停止。落点在预警开始时锁定，不随玩家后续移动回缩。

女神像白天在有存活BOSS时显示 `J 传送至BOSS战斗区`。可携带食物或盘子传送，搬运设施时不能传送。落点位于战斗区靠入口一侧，按玩家实际碰撞体检查墙、设施、敌人与其他玩家；入口拥挤时尝试附近安全点，找不到则保持原位并提示。夜间祈福/技能升级和搬运逻辑保留。

## 干扰头：追踪口水与设施修理

双头交替，各自完成后冷却18秒，交替至少3秒。口水始终锁定1个切/磨/烤台、组合台、酒桶、整套净化池、培养皿或火神炉，优先有物料的设施，跳过已失控对象。口水准备2.5秒、飞行1.8秒、后摇1.5秒，期间巨蜥停步、锁定朝向，给出绕背机会。

锁定与飞行追踪设施本体。即使玩家在命中前将其搬起、移动或重新放置，效果仍附着到同一设施；搬运中的碰撞保持关闭，不强制玩家落地。搬运时头顶显示设施的口水/损坏状态，玩家可自行寻找合法位置放下后修理。

| 状态 | 持续/修理 | 规则 |
| --- | --- | --- |
| 口水附着 | 10秒窗口，空手按住K修理3秒 | 暂停加工、禁止取放；及时修好保住食物 |
| 深度失控 | 普通15秒、半血后30秒 | 进入时摧毁台面食物一次；期间不可修理或提前恢复 |
| 设施损坏 | 深度失控结束后，按住K修理5秒 | 不会自动恢复，修好才重新开放 |

半血强化只延长犯错后的强制失控时间，不缩短10秒窗口，不增加早期或后期修理时长。重攻击不再清理口水。两阶段均禁止设施存取/加工及重新搬起，已在搬运中的设施允许正常安全放置。烤台全熟到焦糊的计时始终继续。

修理接入统一手动工作事件，受工作速度、设施效率增益与池饱饱大招影响，连环快手可消耗一次次数瞬间修理；强制失控尚未结束时不能绕过。修理完成触发工作小技能刷新及大招工作完成效果；中断或重复尝试不触发奖励。

食物损失沿用各设施 `destroy_surface_food()`：成品的实体盘子保留为脏盘，净化池干净/脏盘库存不销毁；酒桶损失当前批次，培养皿损失待收获物但保留种子。击杀BOSS清理尚在附着期的口水，已经深度失控或损坏的设施仍需遵循计时和修理。

## 结构与验证

- `MonitorTongueController.gd` 保留共用运输阶段；`MonitorFeedingController.gd` 负责投喂准备、空地选择、抓取与暴怒，`MonitorFeedingSpot.gd` 负责临时投喂交互及物品守恒。
- `MonitorFacilityTongue.gd` 负责追踪口水；`FacilityWorkPause.gd` 统一管理附着、强制失控及修理，玩家交互层将失控设施焦点转到该效果，避免逐个设施复制修理实现。
- `DesertMonitorBoss.gd` 负责战斗朝向、背后伤害与进食奖励；`BossArenaTravel.gd` 负责安全传送。
- 专项：`validate_monitor_feeding.gd`、`validate_monitor_dual_heads.gd`、`validate_monitor_saliva.gd`、`validate_monitor_boss.gd`、`validate_monitor_playtest_entry.gd`。
- 回归覆盖盘子流程、设施、放置安全、交互焦点、大招能量、小技能变种和正式升级。旧测试夹具已适配正式开局移除技能测试选择的现状。
