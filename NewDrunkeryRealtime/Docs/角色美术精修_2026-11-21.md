# 角色美术精修 · 2026-11-21

本轮接入可疑游商与红鬃羊。背景、料理、设施和 UI 保持当前方向。

## 全员扩展

在已认可的游商与红鬃羊基础上，精修其余 8 位事件 NPC、其余 8 种普通战斗敌人、机制偷料圣甲虫、4 个 BOSS 和女神像。已确认的游商与羊不再修改。

- 普通敌人保留原本的圆厚身体和短肢，通过头部、外壳、羽毛、翅纹及简洁阴影提高完成度；分别使用警觉、憨厚、专注、迷糊等神态，不统一改为邪恶眼神。
- BOSS 保留现有体形、画布与方向，采用更强的眼神、口部和材质对比。巨蜥保持原生朝上方向与尾部位置。
- NPC 按身份分配表情：刻碑师沉稳专注，瓷娃娃安静温和，赌徒自信，偿还者拘谨，炉火精灵活泼，箱中魔鬼诱惑，恶作剧之神戏谑，沙灵神秘；服饰与道具延续原有轮廓。
- 事件头像、对话、屏外指引、图鉴和路牌继续读取原路径，共享更新后的素材。

全员维护入口为 `python tools/character_cast_refinements.py`；可用 `--only enemies`、`--only npcs`、`--only landmarks`。`character_cast_shapes.py` 保存原有身体图层，`character_cast_refinements.py` 负责精修细节与表情；游商与羊仍由 `character_art_refinements.py` 提供。原有三个生成入口保留兼容。

SVG 统一输出默认命名空间，并将八位十六进制透明色展开为六位颜色与 `fill-opacity` / `stroke-opacity`。已通过 Godot 导入后的 25 张纹理导出核对，避免浏览器预览正常而 Godot 丢失带命名空间的身体图层或将透明阴影显示为黑块。

- 可疑游商沿用第四版评审稿：半身与箱子构图、概括五官、狡黠且带危险感的表情。事件头像与场景商人使用同一来源。
- 红鬃羊沿用已认可的圆厚身体、短腿、尾巴、羊毛分块和羊角；表情改为圆眼、略显迟钝的视线和柔和小嘴，避免普通敌人与危险 NPC 共用邪恶表情。
- 普通敌人优先可爱呆萌；BOSS 可以采用更有压迫感的表情。NPC 按具体性格区分，不能将所有角色统一为同一种眼形。
- 明亮感主要来自当前配色。角色结构保持概括和夸张，不通过写实虹膜、鼻梁、关节或长口鼻提升完成度。

## 维护

### 敌人第二轮修订

- 普通敌人用大眼白、小瞳孔表现呆萌；虫类（甲虫、蛾、沙虫、蝎子）与两种植物不画嘴。NPC 保留上一轮结果。
- 四个 BOSS 全面重画：沙虫为弯曲分节长躯和感知点，蝎子为低伏甲壳、八足、螯肢与尾刺，秃鹫为展翼飞行体态、裸颈与钩喙，双头巨蜥为匍匐躯干、长颈吻部、外展四肢和渐细长尾。不再使用圆身体与人脸模板。
- `character_boss_anatomy.py` 为四个 BOSS 的绘制入口。保留现有输出画布尺寸供游戏引用，但不要求动物体形适配圆形；当前碰撞与受击范围尚未按新轮廓调整，需要在造型确认后单独校准。巨蜥仍保持原生朝上方向。

### 敌人第三轮修订

- 普通敌人不再统一使用大眼白：沙原禽、芽甲虫、日光蛾使用豆豆眼，狙击甲虫使用小眼与平直上眼线，骆驼和刺球采用半闭眼，红鬃羊、沙兔、偷料圣甲虫和日光守卫保留大眼白。虫类和两种植物仍然无嘴。
- 沙虫保留第二轮造型；蝎子只将呆滞圆眼改为收紧的甲壳眼窝，身体、螯肢、足与尾刺不变。
- 秃鹫改为头部居中、短颈内收的平衡展翼姿态，双脚收拢，移除原本侧头斜冲的动作。
- 巨蜥按背部俯视重画：去掉浅色中央腹甲与横向腹纹，改为纵向背中线、小背鳞、侧背斑点、肩胯转折和侧面阴影；四肢从肩胯外展，双颈与低伏背部衔接，尾巴从后胯渐细延伸。
- 本轮不改 NPC、沙虫、碰撞和受击参数。

### 巨蜥斜侧视与眼形修订

- 红鬃羊恢复豆豆眼；骆驼改用眼白与小瞳孔。其他已确认的普通敌人与沙虫、蝎子、秃鹫不变。
- 巨蜥采用斜侧视：双吻部前伸、双颈前后遮挡、低伏身体的背面与侧面分层、远侧腿缩小且被身体遮挡、近侧腿落地，尾部从后胯延伸。不再使用完全俯视与对称四肢。
- 巨蜥素材朝左上，运行时旋转使其与逻辑朝向一致；两个舌头视觉起点、后背弱点标记和方向计算同步新图。碰撞形状与受击范围仍留待造型确认后校准。
- 本轮进食专项发现 5 项失败（背后真实近战命中与投喂准备）；临时恢复本轮之前的朝向与舌头坐标后，对照结果完全相同。该专项不能报告为通过，日志与自动恢复的对照脚本保存在外层 `_artifact_work/monitor_oblique_v4/`，待独立排查。

### BOSS 判定适配

- 四个 BOSS 已完成地面阻挡、受击分区与接触伤害拆分，替换旧统一大圆判定；细节与验证记录见《BOSS判定与美术对齐_2026-11-21.md》。上文“尚未校准”的说明为各轮美术修改时的历史状态。

运行 `python tools/character_art_refinements.py --only merchant` 仅生成游商事件图与场景商人；`--only red_lamb` 仅生成红鬃羊。省略参数时转到全员生成入口。

原有敌人、事件和地标生成器均接入该来源。`finish_art_direction.py` 保留标记为 `character-refinement-v1` 的平涂素材，不额外添加渐变或旧装饰。

画布尺寸保持不变：红鬃羊 128×128、事件游商 120×144、场景商人 256×320。碰撞、敌人属性、掉落与交互均不改。
