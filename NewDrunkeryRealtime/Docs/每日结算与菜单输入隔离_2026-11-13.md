# 每日结算与菜单输入隔离

- 每日成功、失败和最终通关共用 `DailySettlementPanel`。日期来自刚结束的关卡，不使用已递增的下一日天数。订单、声望、持有金币、当前经验与等级以六张卡片显示；金币和经验仍为当前状态，不冒充当日收入。
- 营业结果、属性锻造器奖励和事件结算放在可换行、可滚动的纪要区域；标题与继续提示固定在滚动区外。事件通知由主流程传入，再清空待显示通知。显示层不改奖励或结算数据。
- 玩家统一在 `NOTIFICATION_PAUSED` / `NOTIFICATION_UNPAUSED` 记录菜单打开前仍按住的动作键，覆盖 NPC、商店、菜单、祝福、升级、全局强化、结算、暂停与图鉴。所有现有二级菜单都使用游戏暂停，不必逐一在关闭回调中补拦截。
- 保护按动作键分别生效：菜单确认键仍按住时不会变成冲刺／攻击／交互，但新按下的移动、技能等动作可以立即生效；旧键松开后重新按下即可使用。释放边沿同样被屏蔽，避免完成菜单操作时结束攻击蓄力。开关卡过场只按固定时长结束，不再等待确认键松开。
- 新增 `tools/validate_menu_release_and_settlement.gd`：真实 NPC 拒绝交易、空格按住／释放／重新按下、工作／拾取／攻击／技能／移动隔离、暂停和图鉴关闭；两种逻辑分辨率下的长消息边界、成功／失败／最终通关及显示不修改进度。
- 验证截图位于 `_artifact_work/settlement_*.png`；`--capture` 使用实际 OpenGL 渲染。夜间事件、关卡输入、HUD 与失败重开使用各自现有验证脚本。
