# 菜单与食材区域重排（2026-11-21）

## 游戏规则

- 食材引入顺序为中区 → 左区 → 右区。第1–2天的普通菜单仅用中区原料；第3–4天允许左区原料；第5天起允许右区原料。区域仍可自由探索，日期限制只用于菜单候选。
- 中区采集为脆脆芽、碎金子、晴天梅；原沙薯移至右区，替换原碎金子。右区采集为沙薯、莳萝、太阳籽。左区采集不变，莳萝可由左区莳萝沙甲获得。
- 开局保留绿洲葡酒、砂金麦酒、晴梅淡酿，搭配脆芽冷盘与禽肉芽盘；三种酒的原料均可在中区采集。
- 第2天夜间提供中区进阶酒；第3天夜间提供左区花材/莳萝酒；第5天提供高级酒。第3、5天的首次新菜候选优先对应新区域，随后可选已开放区域的菜。
- 普通新增菜、刷新和夜间事件换菜统一按原料阶段筛选。酒水原料也计入来源判断；BOSS菜不进入普通候选池。
- 三种小BOSS均在第4天可能登场，专属客人固定为酒水、小菜、专属主菜；三道菜的非BOSS原料只需中区与左区。最终BOSS菜保留三区组合。
- 全部菜品补齐说明，菜单显示原料阶段，图鉴的来源读取实际分布表。图鉴菜品按原料阶段排列。保持既有加工速度、三种基础酒配方、采集产量及战斗掉落数量。
- 食材隐藏获取层级与价值顺序同步到区域阶段，金币、经验及耐心沿用现有自动计算模型。

## 主要配方调整

| 原菜名 | 新菜名 / 调整 |
| --- | --- |
| 白肉菜盘 | 禽肉芽盘；保留禽肉+脆芽，作为开局主菜 |
| 沙薯凉盘 | 晴梅冷盘；两份切梅 |
| 禽肉沙薯卷 | 禽肉脆芽卷；两份切禽肉+切脆芽，避免与禽肉芽盘配方冲突 |
| 红鬃双烤 | 沙兔双烤；双份半熟兔肉 |
| 沙薯肉排 | 沙薯羊排；右区羊肉与沙薯，配方保留 |
| 双酿酒 | 太阳籽替换为碎金子，保留中区进阶酒路线 |
| 日轮浸酿 | 梅露莳萝酿；太阳籽换晴天梅，作为左区草本酒 |
| 莳萝沙薯盏 | 莳萝菜盏；沙薯换白菜 |
| 莳萝禽锅 | 沙薯换烤麦，并补莳萝细粉，与菜名一致 |
| 晴梅甜羹 | 花细粉换麦细粉，中区可制作甜品 |
| 晴梅炙盏 | 太阳籽换碎金子，左区阶段可制作 |
| 流沙晶髓王庭热盘 | 驼肉换兔肉，太阳籽粉换麦粉 |
| 蝎甲烈阳拼盘 | 羊肉换禽肉 |
