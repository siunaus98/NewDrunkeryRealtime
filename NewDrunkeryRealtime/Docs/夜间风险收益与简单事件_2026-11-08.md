# 夜间风险收益与简单事件

## 本轮实装范围

已接入下一日难度、菜单后的全局强化、随机代价揭示、契约回顾与通关属性奖励。事件部分是设计提案，尚未生成 NPC 或接入事件交互。

流程：白天成功结算 → 选择菜单（需要时先选酒水）→ 选择全局强化 → 揭示未知代价 → 夜间自由备战 → 组合台选择当天难度 → 开始营业。

第一天营业前没有契约和奖励难度。第一至第六天结算后各选择一次契约；第四、第七天营业难度固定，其他后续营业日提供简单、中等、困难三个选项。技能升级依然在女神像完成，未完成时无法进入营业难度界面。

### 下一日难度

- 简单：基础收益，无额外当日难题。
- 中等：随机低/中档奖励与同档当日难题。
- 困难：高档奖励与高档当日难题。
- 两个奖励方案从金币、经验、属性锻造三个方向中抽取，方向不重复。
- 金币/经验额外收益的测试初值为 25% / 50% / 75%，作用于上菜（包含甜品），不增加商店和其他来源的资源。
- 属性奖励为 1 个白银 / 黄金 / 钻石锻造器，仅成功通关后发放，夜间找商人免费选择属性，可保留未领取奖励。
- 同一天三个选项共用基础客人安排；差异来自明确显示的收益与难题。
- 当日难题只在该日备菜与营业期间生效，不污染夜间或下一日；BOSS 日仍会受到之前累计的全局契约影响。

### 全局契约

- 每夜提供三个不同方向，低、中、高强度各一项。玩家只看见收益、强度和会附加随机代价的提示。
- 选择后从同档负面池抽取一项并揭示，确认后进入夜间备战。
- 收益池：上菜金币、上菜经验、手动工作速度、玩家攻击力、玩家移动速度。
- 代价池：敌人移速、敌人攻击伤害、普通/精英客人耐心总量、客人声望惩罚、玩家移速、手动工作速度。
- 排除强化直接抽到自身反向效果的情况，例如工作加速不会在同一次选择中抽到工作减速。
- 各份契约倍率相乘；同强度指配置档位，当前数值是测试初值，尚未证明每种不同机制的实战难度完全等价。
- 工作速度适用于采集、点单、切、磨、洗盘及设施读条工作，不改变自动烤制或酒桶计时，因此不缩短全熟到焦糊的容错时间。
- 特殊客人的接单/耐心独立时钟继续免受耐心修正；声望惩罚和上菜收益仍受对应契约影响。
- 已显示选项、已签契约、随机种子与未领取锻造器进入跨天快照；重复打开不会重抽。
- 夜间组合台新增“全局契约”回顾入口。

### 文件职责

- `Scripts/Progression/RunModifierDefs.gd`：收益/代价内容、测试数值、难度方案生成、敌人出生时的一次性属性应用。
- `Scripts/Progression/RunModifierState.gd`：本局随机种子、固定选项、已选契约、累计倍率、当日效果与快照。
- `Scripts/UI/GlobalModifierSelectController.gd`：复用现有卡片滚动显示收益、揭示结果与契约历史。
- `RunProgressionState` 持有状态；`LevelFlowController` 仅负责流程入口和结算接线。
- `RunSetupController` 改用 `RunProgressionState.get_snapshot()`，避免在多个地方重复列出持久化字段。

## 第一批简单事件提案

> 以下为已被替代的早期提案。当前讨论采用 `Docs/夜间事件设计修订_2026-11-12.md`：事件须有可对话主体，不要求夜间制作或提前囤积料理，玩法以规则变化、取舍与次日机会为主。事件仍未实装。

事件的价值应是改变当夜的资源分配，而不是再复制一份“全局强化+随机惩罚”。第一批采用明确收益、明确成本、当场完成的结构；无强制交互，不影响开启下一天。

| 事件 | 选择与收益 | 特点 |
| --- | --- | --- |
| 沙漠商旅 | 展示一包当前菜单用得上的原料；付金币购买，或离开 | 最容易实现，帮助补齐短缺；先展示内容再付款 |
| 偏科的采集者 | 交出指定数量的一种原料，换取事先展示的另一种原料；或拒绝 | 用富余资源换缺口，交换清单固定显示，排除 BOSS 食材 |
| 见习厨师 | 免费选择一组切好的食材或一组粗磨小料 | 轻量赠礼；明确熟成度、数量和接收位置，不接管自动加工 |
| 流浪锻造师 | 支付较低费用使用一枚白银锻造器，或支付较高费用使用黄金锻造器 | 复用属性锻造，属于可选的特殊商人 |
| 夜行朝圣者 | 支付金币，换 1 次祝福刷新；或保留金币 | 在设施投入与祝福机会间作简单取舍，不消耗夜间会重置的声望 |
| 夜宵客 | 当夜交付事先指定的一道现有菜单料理，领取金币与经验；或不接待 | 无倒计时，不占普通上菜口；复用制作链，开发量高于前五个 |

建议优先实装“沙漠商旅、偏科的采集者、夜行朝圣者、见习厨师”。前两者提供资源取舍，第三者提供消费方向，第四者提供轻松的正向事件，不必每次遇见 NPC 都承担代价。

### 最小事件规则

- 第一至第六天成功结算后的夜间，生成一名可选 NPC；位置先固定在安全、可交互且不会挡路的区域，随机的是事件内容。
- 头顶明显的事件气泡，靠近显示 `J 交互`；已结算后关闭标记，避免反复领取。
- 对话里展示全部成本和收益，始终可以离开；关闭后再次交互保留同一报价。
- 进入下一天时，未处理 NPC 离开，没有额外处罚。
- 实物收益需要明确接收方式。食材包可在选择时明确写“补入对应食材箱”；半成品优先用 NPC 自己的托盘领取，避免随意散落或清空玩家手持物。
- 不能完成的交易不扣款；没有对应食材、没有可用菜单原料等情况不生成该选项。
- 先不做跨天委托、经验扣除导致降级、夜间声望献祭、随机摧毁设施或额外永久效果，这些会引入当前提案不需要的新规则。
